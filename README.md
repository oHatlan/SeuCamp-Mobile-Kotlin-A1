# SeuCamp Mobile

Projeto da A1 de Desenvolvimento de Aplicativos Moveis.

## Proposta

Aplicativo Android para criar torneios de jogos, gerenciar equipes participantes e compartilhar informacoes dos campeonatos.

## Requisitos previstos

- Kotlin com Jetpack Compose.
- Persistencia local com Room.
- CRUD completo de torneios e equipes.
- Consulta a uma API de jogos para selecionar o jogo de cada torneio.
- Compartilhamento das informacoes de um torneio com outro aplicativo instalado no dispositivo.

## Estado atual

Proposta inicial registrada. O aplicativo Android ainda sera desenvolvido.
